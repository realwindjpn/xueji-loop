### 界面整体说明
这是**学记教育网校后台（调度终端/QUEST LOG）**的管理界面，采用复古像素风设计，主色调为深紫+明黄，当前处于无后端预览模式，所有`/api/*`类请求均由本地引擎模拟返回。

---
### 顶部导航栏
1. 左上角为平台名称「学记教育网校后台」，附带3个状态标签：
   - 服务：<kbd>ok</kbd>
   - 学生：<kbd>0</kbd>
   - 待处理：<kbd>0</kbd>
2. 下方黄色通栏：
   - 左侧标识：<kbd>预览模式 · 无后端</kbd>
   - 中间标题：★ QUEST LOG · 调度终端 ★
   - 右侧提示：「预览模式：所有 `/api/*` 由本引擎模拟返回」

---
### 顶部功能标签页
横向排列的功能入口依次为：
<kbd>初始建档</kbd> <kbd>每日反馈</kbd> <kbd>学生列表</kbd> <kbd>调整队列</kbd> <kbd>AI任务队列</kbd> <kbd>学生详情</kbd> <kbd>复售评测校准</kbd> <kbd>学科知识库</kbd> <kbd>家长权益</kbd> <kbd>模型配置</kbd>
当前处于「初始建档」标签页下。

---
### 内容区
#### 1. 老师工作台
说明文案：后台优先处理三件事：看学生风险、处理调整队列、发布前复核方案。AI负责整理初稿，老师负责判断是否适合当前孩子。
下方对应3个功能卡片：
| 卡片标题 | 功能说明 |
| --- | --- |
| 🔵 先看风险 | 学生列表和每日反馈里优先筛查抗拒、疲劳、未反馈和完成率低的学生 |
| 🟢 再处理队列 | 调整队列用于判断是否减量、潜卡回炉、研学保温或生成下一版方案 |
| 🟡 发布前确认 | 方案.DOCX、权益和学生端状态确认后，再发给家长执行 |

#### 2. 初始建档表单
带有「填入样例」快捷按钮，是学生信息录入表单，包含字段如下：
| 字段名 | 填写规则/默认值 |
| --- | --- |
| 学生称呼 | 输入框，填写示例：`小陈` |
| 年级/地区 | 输入框，填写示例：`初一/湖南` |
| 目标 | 输入框，填写示例：`期末基础抢分` |
| 最近考试时间 | 输入框，填写示例：`2周后` |
| 周天可用时间 | 下拉选择框，默认选中`15-25分钟` |
| 配合度 | 下拉选择框，默认选中`一般` |
| 优先科目/考试 | 输入框，填写示例：`语文古诗,历史道法,英语基础词` |
| 最大画框 | 界面未展示完整选项 |
