# 学记教育闭环后台界面描述
整体为复古像素风格的教育管理后台，主色调为深紫色+明黄色，视觉设计仿照游戏任务终端样式。

---

## 顶部导航区
1. 最上方左侧是系统名称**学记教育局闭环后台**，旁侧附带三个状态标签：
   - 服务状态：`ok`
   - 学生数量：`0`
   - 待处理任务：`0`
2. 下方黄色通栏：
   - 左侧标注：`预览模式 · 无后端`
   - 中间为栏目标识：`★ QUEST LOG · 调度终端 ★`
   - 右侧技术提示：`预览模式：所有 /api/* 由本引擎模拟返回`

---

## 功能标签栏
横向排列10个功能入口：
`初始建档`、`每日反馈`、`学生列表`、`调整队列`、`AI任务队列`、`学生详情`、`复读评测校准`、`学科知识库`、`家长权益`、`模型配置`

## 内容区
### 1. 老师工作台模块
模块说明文字：
> 后台优先处理三件事：看学生风险、处理调整队列、发布前复核方案。AI负责整理初稿，老师负责判断是否适合当前孩子。

下方分为三个功能卡片：
| 卡片标题 | 内容说明 |
| ---- | ---- |
| 🔵 先看风险 | 学生列表和每日反馈里优先看抗拒、疲劳、未反馈和完成率低的学生。 |
| 🟢 再处理队列 | 调整队列用于判断是否减量、潜卡回炉、研学保温或生成下一版。 |
| 🟡 发前必确认 | 方案.DOCX、权益和学生端状态确认后，再发给家长执行。 |

---

### 2. 初始建档模块
配有`填入样例`快捷按钮，下方为学生信息录入表单：
| 字段名 | 填写提示/默认值 |
| ---- | ---- |
| 学生偏好 | 输入框，示例：`小陈` |
| 年级/地区 | 输入框，示例：`初一/湖南` |
| 目标 | 输入框，示例：`期末基础抢分` |
| 最近考试时间 | 输入框，示例：`2周后` |
| 每天可用时间 | 下拉选择框，默认值：`15-25分钟` |
| 配合度 | 下拉选择框，默认值：`一般` |
| 优先科目/考试 | 输入框，示例：`语文背古诗,历史背法,英语基础词` |
| 最大难度 | 输入框，无预设示例 |
