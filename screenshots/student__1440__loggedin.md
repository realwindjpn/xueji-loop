这是**学记学生端**的预览登录页，整体采用深棕底色+暖金色点缀的暗色UI设计，当前处于未对接后台服务的演示状态，具体内容如下：
1.  页面左上角有金边提示标签：`预览模式·无后端`
2.  主卡片顶部信息：
    - 左侧是带金色圆点标识的产品名「学记学生端」，下方有红色的接口报错提示：`Unexpected token 'o', "not found" is not valid JSON`
    - 右上角有金色边框功能按钮：<kbd>家长端已确认的学习安排</kbd>
3.  产品特性介绍区有3个并列的功能说明卡片：
    | 功能名称 | 功能说明 |
    | ---- | ---- |
    | 只看今天 | 不用翻整套计划，打开就是当天该做的内容。 |
    | 先听再说 | 英语跟读会保留练习记录，方便之后回看。 |
    | 错卡回炉 | 知识卡可展开答案，按反馈进入下一轮复习。 |
4.  账号登录区：
    - 依次是「手机号」输入框、「密码」输入框，右侧对应<kbd>登录</kbd>、<kbd>退出</kbd>两个操作按钮
    - 输入框下方提示：*请输入学生手机号和密码，或由家长端进入。*
5.  底部提示栏（左侧带金色竖线标识）：
    > 学生端只呈现学习任务和复习卡，不展示家长管理信息。遇到不会、太累或完成不了，可以让家长在每日反馈里说明。
