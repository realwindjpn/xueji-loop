这是**学记教育家长端**的未登录页面，整体采用深黑底色+暖金色点缀的暗色UI设计：
1.  全局提示信息
    - 左上角标注：`预览模式·无后端`
    - 右上角标注：`连接异常`，同时附带提示框说明「预览模式：所有 /api/* 由本引擎模拟返回」
2.  页面核心内容分为两部分：
### 左侧产品介绍区
顶部是「我的帐号」模块，说明该区域可查看学生档案、学生端绑定和当前服务状态，当前状态为`未登录`。
下方是产品核心价值介绍：
- 主标题：`先把孩子的学习闭环跑通`
  说明：不承诺神奇提分，只把「今天做什么、做得怎么样、明天怎么调」变清楚。家长能看到过程，学生端只保留当日任务和复习卡。
- 三个核心特点卡片：
  | 特点 | 说明 |
  | ---- | ---- |
  | 7天 | 试运行先验证节奏，再决定是否长期跟进 |
  | 1人1档 | 按教材范围、薄弱点和家庭执行条件生成计划 |
  | 可复核 | AI先整理，关键调整保留人工判断和家长确认 |
- 流程说明：
  1.  先建档，明确年级、范围、薄弱点和可用时间
  2.  先给家长看初步规划，确认后再生成知识卡
  3.  学生端只显示今日任务，减少选择和干扰
- 补充说明：资料只用于生成学习计划、知识卡和反馈分析；遇到研学、疲劳、抗拒等情况，可以通过每日反馈进入下一版调整。
- 底部提示：`暂无学生档案`，登录后可以在「建档」里创建第一个学生。

### 右侧登录区
标题为「登录学记」，提供账号登录入口：
- 手机号输入框：提示输入「中国大陆11位手机号」
- 密码输入框
- 暖金色「登录」按钮
- 注册引导：还没有账号？<u>注册账号</u>
