# 学记教育家长端登录页（预览模式）
整体采用深棕色暗金风格UI设计，当前为无后端预览状态。

## 页面标识
1. 左上角：`预览模式·无后端`标签
2. 顶部居中：页面主标题「学记教育家长端」
3. 右上角：「可注册」标识，同时悬浮提示框标注：*预览模式: 所有 /api/* 由本引擎模拟返回*

## 主体内容区
### 左侧产品介绍区
顶部显示「我的帐号」模块，说明文字为「查看学生档案、学生端绑定和当前服务状态」，当前状态标注为 **未登录**。

#### 核心价值说明
大标题：**先把孩子的学习闭环跑通**
说明文案：不承诺神奇提分，只把"今天做什么、做得怎么样、明天怎么调"变清楚。家长能看到过程，学生端只保留当日任务和复习卡。

##### 核心特点卡片
| 特点标识 | 说明 |
| --- | --- |
| 7天（蓝色标） | 试运行先验证节奏，再决定是否长期跟进。 |
| 1人1档（绿色标） | 按教材范围、薄弱点和家庭执行条件生成计划。 |
| 可复核（红色标） | AI先整理，关键调整保留人工判断和家长确认。 |

##### 使用流程
1. 先建档，明确年级、范围、薄弱点和可用时间
2. 先给家长看初步规划，确认后再生成知识卡
3. 学生端只显示今日任务，减少选择和干扰

##### 补充说明
> 资料只用于生成学习计划、知识卡和反馈分析；遇到研学、疲劳、抗拒等情况，可以通过每日反馈进入下一版调整。

底部提示：**暂无学生档案**，小字说明：登录后可以在"建档"里创建第一个学生。
