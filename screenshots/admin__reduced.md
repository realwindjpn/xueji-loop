这是一套**复古像素游戏风格的学记教育局域网后台管理系统界面**，整体采用深紫+明黄的配色，设计模拟游戏任务日志的视觉效果，具体结构如下：
### 顶部全局栏
1.  最上方左侧是系统名称「学记教育局域网后台」，旁侧附三个状态按钮：
    <kbd>教务 ok</kbd> <kbd>学生 0</kbd> <kbd>待处理 0</kbd>
2.  下方黄色通栏导航：
    - 左侧标识：<kbd>预览模式 · 无后端</kbd>
    - 中间标题：`★ QUEST LOG · 调度终端 ★`
    - 右侧提示：`预览模式：所有 /api/* 由本引擎模拟返回`

### 二级功能导航
一排功能入口按钮：
<kbd>初始建档</kbd> <kbd>每日反馈</kbd> <kbd>学生列表</kbd> <kbd>调整队列</kbd> <kbd>AI任务队列</kbd> <kbd>学生详情</kbd> <kbd>发育评测校准</kbd> <kbd>学科知识库</kbd> <kbd>家长权益</kbd> <kbd>模型配置</kbd>

### 内容区
#### 1. 老师工作台
说明文字：后台优先处理三件事：看学生风险、处理调整队列、发布前复核方案，AI负责整理初稿，老师负责判断是否适合当前孩子。
下方为三个并列的处理模块卡片：
| 模块 | 说明 |
| ---- | ---- |
| <font color="#0277bd">先看风险</font> | 学生列表和每日反馈里优先看抗拒、疲劳、未反馈和完成率低的学生。 |
| <font color="#2e7d32">再处理队列</font> | 调整队列用于判断是否减量、潜卡回炉、研学保温或生成下一版。 |
| <font color="#ef6c00">发前确认</font> | 方案.DOCX、权益和学生端状态确认后，再发给家长执行。 |

#### 2. 初始建档
附<kbd>填入样例</kbd>按钮，下方为学生信息录入表单：
| 表单项 | 填写示例/默认值 |
| ---- | ---- |
| 学生偏好 | 输入框，示例：`如：小陈` |
| 年级/地区 | 输入框，示例：`如：初一/湖南` |
| 目标 | 输入框，示例：`如：期末基础抢分` |
| 最近考试时间 | 输入框，示例：`如：2周后` |
| 每天可用时间 | 下拉选择框，默认值：`15-25分钟` |
| 配合度 | 下拉选择框，默认值：`一般` |
| 优先科目/考试 | 输入框，示例：`如：语文古诗,历史道法,英语基础词` |
| 重大困难 | 空白输入框 |
